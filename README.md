The company is building a video game store. The frontend UI has already been constructed. Here, I will build the backend that powers it. 

The Game Store REST API will be used to expose the data from the Game Store Database. 

Uses: C#, .NET

#Useful commands

##Start application in Development environment
```
cd asp.net/GameStore.Api
dotnet run
```
